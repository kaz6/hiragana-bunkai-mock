## D-031 ★の数え方を「道すじの長さ」で重みづける（作者 2026-11-19 21:05「数え直しで重みつけてあげましょう」）

- 決めたこと（Notion の要点）：声と★を、作り替えた字の「枚数」ではなく、投げた言葉の各字の道すじ（D-023 の d）にある作り替えの回数（「→」の数）の合計で数える。割る・くっつける・向きで別の字になる、がそれぞれ1。字にならない向きをたどった分は数えない。合計1＝ナイス★、2〜3＝グレート★★、4以上＝エクセレント★★★（しきい値は編集の仮置き）
- 理由：21:03 の「けいす」の「け」は4手かけたのに、回すだけの字と同じナイス1つだった（D-020 の「数え方の限り」）
- 実装（HB-009）
  - index.html の STAR_AT=[1,2,4]（この値以上で★が1つずつ増える）と starsOf(k) の1か所にまとめた。工夫の数 k は comboOf（道すじの「→」の合計）。声・リストの★・今日の一語・辞書の★はすべて starsOf(k)。ログは「★エクセレント（工夫4）」と合計を出す
  - 道すじの作りは今のまま。回す・裏返すは「はじめの道すじ→今の字」に置き換わるので、字にならない向きを経由しても1回、元の字に戻れば0回。同じ札を回して字を何度変えても、向きの分は1回（例：し→つ→し… は数えない、し→つ は1）
  - CPU の投げ・ふたりでの相手の投げも同じ数え方（ふたりでは throws の stars に k を入れる。今までどおり9で頭打ち）
  - 辞書（hb.zukan）に前の版で残った k は「枚数」で数えた値のまま。読み替えはしない（★が1つ減って見える語があるだけ。数え直す材料が残っていない）
- 確認（Playwright、390px）：し→回す・裏返す→つ、は→割る→よ＋｜、｜＋し→い で「つよい」＝★エクセレント（工夫4）。こ→割る→一一、一→回す→｜、｜＋一→十、｜＋十→け で「たけ」＝エクセレント（工夫5。け の道すじ ｜＋（（こ→一→｜）＋（こ→一）→十）→け）。こ→回す→い で「いし」＝★ナイス（工夫1）。は割り＋｜＋し で「よい」＝グレート（工夫3）、リスト・今日の一語・辞書とも★★
