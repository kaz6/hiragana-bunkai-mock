## 現在の進捗

- HB-001：モックを公開リポジトリに移し、GitHub Pages で開けるようにした
- HB-002：合言葉の部屋で通信対戦（Supabase Realtime）。はじめの画面に「ひとりで（CPU）」「ふたりで（合言葉）」
  - 二人がそろうと3秒数えて同時に始まる。二人とも在室になるまで投げられない
  - 投げた言葉は表 throws に入れて相手に届く。同じ言葉は主キーの重複（23505）で先着が決まり、負けた側は札を手元に残す
  - 相手が抜けると「相手がいなくなった」で終わる。カゴがあふれた側は「負けた」を送る
  - 確認：Playwright で別々のブラウザ2つ（同じ合言葉）。入室・開始、片方の投げが相手のリストに出る、同時投げは片方だけ通る、抜けると終わる、ひとりで（CPU）は辞書4394語で動く（13/13）
- HB-003：題名の下に「？ 遊び方」ボタン（既存の「しくみ」を開く）。題名は折り返さない（「モック」を消した）。「しくみ」に割れない字の段（データから生成。8字、よ・ろ・の は枠で目立たせる）。シートはどこをタップしても閉じる（スクロールでは閉じない。折りたたみの見出しだけ例外）。遊びの中身は変えていない
- 投げられない並びで「投げる」を押すと、ログに「投げようとした「…」（理由）」が残る（D-027）
- HB-004：手選びの言葉に あほ・すこ・すめし を足した（辞書 4397 語。D-028）
- HB-005：「ことばの表にない」ではじかれた並び（2字以上）を Supabase の rejects に送る。起動時に extra_words を読んで辞書に足す（CPU は使わない）（Notion の D-027）
  - 確認：ひとりでで2つはじかせて rejects に2行（うい・るう、mode cpu）。同じ並びの再選択は送られない。ふたりででは mode online（すぬ）。extra_words に試し語「るう」を入れると語数 4397→4398、投げられた、HAND には入らない。ひとりで（CPU が投げる）・ふたりで（入室・投げが届く）も動いた
  - 試しのデータは作者の OK（2026-11-19）で消した：extra_words の「るう」、rejects の id 1〜29（テストではじかせた分）。id 30〜36 は作者か友人のプレイと見て残した
- HB-006：CPU の速さに「ゆるゆる」（約25秒に1回、投げるのは2字だけ）を足した。並びは とまる→ゆるゆる→のんびり→ゆっくり→ふつう。初めは のんびり のまま
  - 速さの保存を番号（hb.speed）から名前（hb.speedName）に変えた。前の版で覚えた番号は、足す前の並びで読み替える（のんびりのままの人がゆるゆるにずれないように）
  - 確認：ボタンの一周の順、ゆるゆるの待ち時間 22.1〜24.5秒（3回）、CPU が444回投げてすべて2字。ゆっくり・ふつうは3字も投げる。ふたりでも入室・投げが届く
- HB-007：投げた言葉の意味（漢字・英語）を、投げた瞬間に大きく出し、リストに小さく残す（Notion の D-028）。データは meanings.js（JMdict, CC BY-SA 4.0）。3245 語に意味あり、1152 語はなし。「しくみ」に設定（なし／漢字だけ／漢字＋英語）
  - 確認（390px）：はし（橋・端・箸）・よーよー（ヨーヨー / yo-yo）・つよい（強い）が出て1.5秒で消え、リストに残る。意味のない語（よろし）は何も出ない。設定3つが効き、読み直しても覚えている。CPU の投げ（しい）にも出る。ふたりででも相手の画面に出る。声と同時なら声の下に並ぶ
