# はじめの画面の試作（HB-099。D-118）

相談チャットが 2026-11-27〜28 に作った試作。公開ページには入っていない。はじめの画面の形が決まったら、係のカードでこれを元に index.html に入れる。

- `genko-anim.js`：背景の作文用紙。用紙の左上の角だけ見せ（`window.__gkX0`・`__gkY0` で角の位置。0・0 なら画面いっぱい）、字を10ほど散らす。同時に4字まで、部品に割れてマス目を越えて離れ、細い線でつながったまま戻ってくっつく。2字は回るだけ。割れ方は `HB_TEST.RECIPE`（試作ではテストの窓から借りている。本番では index.html の中から直に読む）
- `grid-buttons.js`：「ひとりで」「ふたりで」を背景のマス目にそろえて書く（大きい字は2×2マス、小さい行は1マス1字）。A＝赤ペンで囲む、B＝マスを朱で塗る（`window.__gbMode`）
- 動かし方：テストの形（`openGame` のあと `page.evaluate` で読み込む）。試作なので、動きを減らす設定では止まる（`window.__gkForceMotion` で無視できる）
- 絵：`docs/reports/img/hb099-*.jpg`（ボタン2案・ボタンを外した画面・用紙を画面いっぱいにした画面・紙片のボタン）
