ひらがな分解（仮）

ふたりで：同じ合言葉を入れた二人がそろうと、3秒後に同時に始まる。Two players: when both enter the same room code, the game starts 3 seconds later.

しくみHow it works

    意味を出すShow meanings

    投げた言葉の漢字・英語を、投げた瞬間に大きく出し、リストに小さく残す

    字の大きさText size

    案内Guide

    はじめての1戦では、触る場所の横に一言ずつ案内が出る。

    割る ⇄ くっつけるSplit ⇄ Join

    くっつけるときだけの作り方：し＋｜→い、に＋一→た、り＋一→け、一＋め→あ、わ＋゜→ね、｜＋ま→ほ

    ゜＋゜で濁点「゛」。字＋゛で濁音（は＋゛→ば）、字＋゜で半濁音（は＋゜→ぱ）。濁音・半濁音の字は袋からは出ない。カゴを空にするとすぐ濁音が、1こになると半濁音が落ちてくる。

    黄色い札は、まだ字になっていないもの（部品か、向きの違う字）。言葉には使えない。

    割れない字Letters that can’t be split

    向きを変えてもどうにもならない字。相手に押し付けると重い。

    のばす音Long sound

    寝かせた棒（一）は、のばす音「ー」として言葉の中に置ける。頭には置けない。投げた「ー」は、棒として相手のカゴに届く。

    向きで変わる字（見ると探す楽しみが減る）Letters that change when turned (spoiler)
    • く ⇄ へ：回す
    • い ⇄ こ：回す
    • ｜ ⇄ 一：回す
    • さ ⇄ ち：裏返す
    • し ⇄ つ：回して、裏返す
    • ぐ ⇄ べ、ざ ⇄ ぢ、じ ⇄ づ：もとの字と同じ（ほかの濁音・半濁音の字は向きで変わらない）
    • ゛：回しても裏返しても変わらない

    回すと裏返すは、どの札でも押せる。意味のある向きになったときだけ別の字になる。

    きまりRules

    リストに出た言葉は、二人とも二度と投げられない。

    字は自分では引けない。カゴが 2こ以下になって 5秒たつと、3こになるまで落ちてくる（二人とも）。14こ のときは割れない。

    作り替えた字（割った・回した・裏返した・くっつけた字）が入った言葉を投げると声が出る。言葉の字それぞれの道すじにある作り替えの回数（「→」の数）を合わせて、1で★、2〜3で★★、4以上で★★★。リストにも★が残り（二人とも）、終わったら二人それぞれの★がいちばん多い言葉が「今日の一語」に出る。元の字からの道すじ（例：し→つ　は→よ　（は→｜）＋し→い）つき。どれも見た目だけで、勝ち負けには関わらない。

    このモックで仮に置いたもの

    • 落ちてくる字は袋から出る（中身は28種類。濁音・半濁音の字は入れていない）
    • 使える言葉は 語。2字は手で並べたもの、3字以上はそれに IPADIC（固有名詞としてしか載っていない語は有名な地名のほかは除き、形容詞の「〜く」の形を足した。tools/build_dict.js で作る）を足したもの。正しい言葉でも通らないことがある
    • ふたりで遊ぶときは、相手は人（合言葉の部屋）。カゴや袋は各自の端末の中で動き、投げた言葉と、カゴの札の並び（「あいて」の行に出る）が相手に届く。自動の相手は、ひとりで遊ぶときだけ
    • 相手は自動。最初に手を動かすまで待っている。知っているのは手で並べた3字までの言葉だけで、長い言葉は狙わない（IPADIC の言葉は使わない）
    • 割る・回す・裏返すはボタン。「落として割る」はまだ入れていない
    • いくつか選んでいるときの回す・裏返すは、最後に選んだ札（ふちどり）にかかる。選んだままなので、そのまま投げられる
